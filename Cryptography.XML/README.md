# Utilities.DotNet.Cyptography.XML

## About

The _Utilities.DotNet.Cyptography.XML_ package provides XML cryptography-related classes.

## Usage

### Extensions to SignedXml

The following extension methods for `System.Security.Cryptography.Xml.SignedXml` are provided:

| Method | Description |
|--------|-------------|
| GetSubjectKeyIdentifier | Gets the Subject Key Identifier. |
| GetSubjectKeyIdentifierBytes | Gets the Subject Key Identifier bytes. |

### Extensions to KeyInfo

The following extension methods for `System.Security.Cryptography.Xml.KeyInfo` are provided:

| Method | Description |
|--------|-------------|
| GetSubjectKeyIdentifier | Gets the Subject Key Identifier. |
| GetSubjectKeyIdentifierBytes | Gets the Subject Key Identifier bytes. |
